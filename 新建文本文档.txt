# Roomie - 家庭协同小程序

## 项目概述

Roomie 是一个专为家庭和同住成员设计的协同生活小程序，提供一个共享的生活协同空间。成员加入同一个"同屋"后，可以一起记录家庭清单、安排日程、查看动态，让家庭事务不再分散在聊天工具中。

## 核心功能

### 1. 同屋管理
- 创建同屋（家庭空间）
- 加入同屋（通过邀请码或链接）
- 同屋信息管理（名称、描述、头像）
- 同屋成员管理（添加、移除、权限设置）

### 2. 家庭清单协作
- 创建家庭清单（购物清单、待办事项、任务分配）
- 任务分配给成员
- 任务状态更新（待完成、进行中、已完成）
- 清单分类和标签
- 任务提醒和截止时间

### 3. 家庭日程管理
- 共享家庭日程
- 个人日程与家庭日程区分
- 日程提醒功能
- 重复日程设置
- 日程分类（工作、家庭、个人）

### 4. 动态与沟通
- 家庭动态发布
- 任务完成动态
- 成员状态更新
- 简单的评论和点赞功能

### 5. 个人中心
- 个人信息管理
- 我的任务查看
- 主题设置（换肤功能）
- 通知设置
- 退出同屋

## 技术需求

### 技术栈
- 框架：uni-app x (Vue 3 + TypeScript)
- 后端：Node.js + Express 或 Koa
- 数据库：MongoDB 或 MySQL
- 部署：微信小程序云开发或独立服务器

### 架构设计
- 前端：组件化开发，MVVM架构
- 网络层：统一的API请求封装
- 状态管理：Vuex/Pinia 或 Composition API
- 路由：uni-app x 路由系统
- 存储：本地存储 + 云存储

### 换肤系统
- 支持多种主题（默认、深色、自定义）
- 颜色主题（主色调、辅助色、背景色）
- 图片资源（图标、背景图）
- 主题配置持久化
- 实时切换效果

## 界面设计需求

### 设计原则
- 简洁直观：界面清晰，操作简单
- 家庭友好：温暖的色彩，亲切的图标
- 移动优先：适配不同屏幕尺寸
- 无障碍设计：考虑不同年龄层使用

### 主要页面
1. 启动页：Logo展示，权限请求
2. 登录页：微信授权登录
3. 同屋选择页：创建/加入同屋
4. 主页：任务概览、日程提醒、最新动态
5. 清单页：任务列表、添加任务
6. 日程页：日历视图、添加日程
7. 动态页：家庭动态流
8. 个人中心：设置、主题选择

### 主题系统界面
- 主题预览卡片
- 颜色选择器
- 图片上传/选择
- 主题应用按钮

## 性能需求

- 启动时间：< 3秒
- 页面切换：< 500ms
- 网络请求：< 2秒超时
- 内存占用：控制在合理范围内
- 离线功能：基本浏览和编辑

## 安全需求

- 用户数据隔离：不同同屋数据完全隔离
- 权限控制：成员权限分级（管理员、普通成员）
- 数据加密：敏感信息加密存储
- 隐私保护：不收集无关个人信息
- 合规性：符合微信小程序审核标准

## 主题系统使用

### 切换主题
```typescript
import { switchTheme } from '@/common/themes'

// 切换到指定主题
switchTheme('dark') // 切换到深色主题
switchTheme('fresh-green') // 切换到清新绿主题
```

### 创建自定义主题
```typescript
import { themeManager } from '@/common/themes'

const customTheme = {
  name: '我的主题',
  primaryColor: '#FF6B35',
  secondaryColor: '#FF8C42',
  backgroundColor: '#FFF8F3',
  textColor: '#2D3748',
  cardBackground: '#FFFFFF',
  borderColor: '#FED7CC'
}

themeManager.createCustomTheme(customTheme)
```

### 订阅主题变化
```typescript
import { subscribeTheme } from '@/common/themes'

const unsubscribe = subscribeTheme((theme) => {
  console.log('主题已切换:', theme.name)
  // 处理主题变化逻辑
})

// 取消订阅
unsubscribe()
```
